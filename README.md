## 🌟 TÍNH NĂNG NỔI BẬT

1. **Chuẩn mực sư phạm 6 phần trong mỗi chương:**
   - **1. Bản chất vật lý:** Lý do đại lượng ra đời, ý nghĩa trực giác, điều kiện áp dụng và giới hạn lý thuyết.
   - **2. Công thức & Chứng minh từng bước:** Giải thích tường minh lý do biến đổi toán học ở từng bước (tuyệt đối không viết *"dễ thấy"*), kèm hình vẽ vector trực quan bằng SVG.
   - **3. Phân dạng bài tập:** Thuật toán 4 bước chuẩn mực (*Mô hình hóa $\to$ Giản đồ lực FBD $\to$ Phương trình định luật $\to$ Nghiệm giải tích $\to$ Kiểm tra thứ nguyên*).
   - **4. Ví dụ mẫu chuyên sâu:** Đề bài thực tế, phân tích hướng tư duy và lời giải chi tiết.
   - **5. Lỗi thường gặp & Mẹo kiểm tra:** Nhận diện các bẫy đề thi, mẹo thử cận biên và phân tích thứ nguyên.
   - **6. Hệ thống 10 bài tập thực hành/chương:** Đúng chuẩn phân loại **4 Dễ - 4 Vừa - 2 Khó** (tổng cộng **170 bài tập** tính toán chuẩn xác).

2. **Hệ thống chấm điểm & Tương tác thông minh:**
   - **Hộp nhập đáp số tự động chấm:** Hỗ trợ sai số cho phép $\pm 2\% - 5\%$.
   - **Phản hồi tức thì:** Báo đúng/sai ngay lập tức bằng giao diện trực quan.
   - **Gợi ý & Lời giải ẩn (Accordion):** Cho phép xem gợi ý từng bước hoặc mở bung toàn bộ lời giải chi tiết khi cần.
   - **Thang điểm 10 cuối chương:** Đánh giá năng lực và phản hồi mức độ nắm bắt kiến thức sau khi hoàn thành các bài tập.

3. **Công cụ học tập nâng cao:**
   - 🔍 **Tìm kiếm thời gian thực:** Tra cứu nhanh chương, công thức, khái niệm ngay trên thanh tìm kiếm.
   - 🖨️ **Bảng công thức in ấn:** Chế độ xem toàn bộ công thức hệ thống, tối ưu hóa cho lệnh in ấn (`@media print`).
   - 🎲 **Chế độ Ôn tập ngẫu nhiên:** Trộn ngẫu nhiên câu hỏi từ kho 170 bài tập đa chương để luyện phản xạ trước kỳ thi.
   - 💾 **Lưu trữ tiến độ học tập:** Ghi nhớ trạng thái làm bài tự động bằng `localStorage` (có bọc `try/catch` an toàn).
   - 🌓 **Chuyển đổi Giao diện Sáng / Tối (Dark/Light Mode):** Tối ưu độ tương phản, chống mỏi mắt khi học lâu.
   - 📐 **Hiển thị công thức sắc nét:** Render LaTeX chuẩn xác với KaTeX CDN tốc độ cao.

## 🚀 HƯỚNG DẪN ĐẨY LÊN GITHUB & KÍCH HOẠT GITHUB PAGES

Kho mã nguồn đã chứa sẵn tệp `index.html` tại thư mục gốc. Bạn có thể triển khai lên mạng chỉ với các bước sau:

### 1. Đẩy code lên GitHub
Mở Terminal hoặc Command Prompt tại thư mục dự án và chạy:

```bash
# 1. Đặt nhánh chính là main
git branch -M main

# 2. Thêm remote trỏ đến repository của bạn trên GitHub (thay username/repo tương ứng)
git remote add origin https://github.com/<your-username>/<your-repo-name>.git

# 3. Đẩy toàn bộ mã nguồn lên GitHub
git push -u origin main
```

### 2. Kích hoạt GitHub Pages (2 nhấp chuột)
1. Trên trình duyệt, truy cập vào Repository GitHub của bạn.
2. Vào mục **Settings** $\to$ Chọn **Pages** (ở menu bên trái).
3. Tại mục **Build and deployment** > **Source**:
   - Chọn `Deploy from a branch`.
   - Branch: chọn `main`, thư mục chọn `/ (root)`.
   - Nhấn **Save**.
4. Chờ 30 giây đến 1 phút, GitHub Pages sẽ cấp cho bạn đường link website trực tiếp có dạng:
   👉 **`https://<your-username>.github.io/<your-repo-name>/`**
